# Hard rule: deny gh and curl permission requests

**Status**: Accepted. Complements `2026-11-24-soft-rule-fallback.md`.

## Context

The soft rule is an instruction in the system prompt. Agents can still ignore it and run `gh` or `curl` against GitHub, bypassing the policy, the cache and the rate-limit handling. Paseo's `agent.permission.before` hook fires when a permission becomes pending. Its `request.input` carries the shell command text (`command` or `cmd`), and `context.paseo.agents.ref(id).respondToPermission` can answer it with `{ behavior: "deny", message }`. So a plugin can refuse a command before it runs.

## Decision

1. A second setting, `blockRawGithub` (off by default), shown as **Block gh/curl commands (hard)** next to the soft rule.
2. `server/hardrule.ts` registers on `agent.permission.before`. While the setting is on, a request whose command runs `gh`, or `curl` or `wget` with a GitHub host (github.com, githubusercontent.com and their subdomains) is denied. The message addresses the agent, names the hard rule, points to the `github_*` tools and says not to retry.
3. Detection is pattern matching on command words: the text is split on pipes, `&&`, `;`, newlines and subshells, then env assignments and prefixes (`sudo`, `env`, `time`, `timeout`, `xargs`, ...) are skipped, and `bash -c`, `eval` and `$(...)` are scanned recursively (depth 3). `git` and `grep gh` do not match. It favors few false positives over completeness.
4. Each denial is logged in the Activity tab as status `denied`, tool `hard rule`.

## Consequences

- It only applies when the agent raises a permission request. An agent in a bypass or auto-approve mode never does, so nothing is blocked there. Requests the rule does not match stay pending for the user.
- It is not a sandbox: a script file, a variable, an alias or a command built at run time gets through. A real block needs network or egress rules on the daemon machine. The UI, README, website and listing say so.
- A failed denial (for example, the request was already resolved) is logged to the console and not recorded in Activity.
