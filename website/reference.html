Tools

Every agent has these. Related operations are grouped behind one tool with an operation input, and each operation has its own action. The repository documents every gh command and what is left out in docs/gh-parity.md. repo is owner/name and can be omitted: it is inferred from the origin remote of the agent's working directory.

Presets

PresetAllows by default
Read-onlyread, generic_api_read
PR workflowRead-only plus comment, review, create_issue, create_pr, update_pr, create_branch, manage_labels, manage_notifications, subscribe_events
Full (default on a fresh install)Every action, including generic_api_read and generic_api_write

Changing an individual permission makes the policy Custom unless it matches a preset.

Upgrading: an action added after your policy was saved is allowed where an implying action is allowed, in the default permissions and in rules that list actions: create_branch where create_pr is, manage_labels where update_pr is, subscribe_events where comment is. Destructive and admin actions (write_file, releases, Actions, variables, repository creation and editing, gists, notifications, projects) are never implied; check them yourself. A denial names the action and the rule or default policy, and tells the agent to ask you to enable it in the Policy tab.

Rules

A rule has an effect (allow or deny), repository patterns, actions (or all), and an optional reason that is shown to the agent in the denial. For each needed action: a matching deny rule denies; otherwise a matching allow rule allows; otherwise the default permissions decide. Rule order does not matter.

Patterns are owner/repo, case-insensitive. * matches any run of characters inside one part: acme/*, */docs, acme/web-*. A lone * matches every repository.

Allowed owners

Checked before the policy. Exact, case-insensitive; * allows all; the default is *; an empty list refuses everything. Paths that name no owner (/user/repos, a search without repo:, org: or user:, a GraphQL call without repo) are refused unless * is allowed.

The page

  • Overview: remaining and limit per credential (gh and each GitHub App) and resource, a reset countdown, a requests-per-minute chart, the cache hit rate, when webhooks are on the events received, delivered to a subscriber, ignored and rejected with their own per-minute chart, and banners when a limit is nearly or fully used up or no owner is allowed.
  • Auth: source choice, gh check, the list of GitHub Apps (add, edit, remove, organization, also-serves owners, default, a step by step test connection), fallback toggle, allowed owners.
  • Policy: presets, default permissions, rules, the dry-run box, the soft and hard rules, the cache TTL.
  • Activity: a live log of calls per agent: tool, repository, allowed, cached, revalidated, denied or failed, HTTP status, the source (and the App that served it) and duration. Tap a row for the full message.
